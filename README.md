# C++ 開発環境 (Docker + CMake)

コンテナ化された最新のC++開発環境です。CMake、GoogleTest、および各種静的・動的解析ツールが統合されており、複数のアプリケーションを効率的に開発できます。

## 概要

このプロジェクトは、Dockerを使用してC++のビルド、テスト、解析を行うための一貫した環境を提供します。主に以下の要素で構成されています。

  * **コンテナ環境**: `ubuntu:24.04` をベースとし、開発に必要なツールがプリインストールされています。
  * **ビルドシステム**: `CMake` を使用し、複数のアプリケーション (`app1`, `app2`) を管理します。
  * **テスト**: `GoogleTest` (`gtest`) を `FetchContent` を利用して導入し、ユニットテストを記述できます。
  * **開発支援ツール**:
      * 静的解析: `cppcheck`
      * メモリ解析: `valgrind`
      * コードカバレッジ: `lcov` / `genhtml`
  * **便利スクリプト**: ビルド、テスト、クリーンアップを簡単に行うためのシェルスクリプトが用意されています。

## 使い方

### 1\. 環境の起動

`docker-compose` を使って、Dockerコンテナをビルドし、バックグラウンドで起動します。

```
docker-compose up -d --build
```

### 2\. コンテナに入る

開発作業はすべてコンテナ内で行います。以下のコマンドでコンテナのシェルにアクセスします。

```
docker-compose exec cpp-dev bash
```

以降のコマンドは、コンテナ内の `/workspace` ディレクトリで実行してください。

## 開発ワークフロー (コンテナ内での操作)

### プロジェクトのビルド

`build.sh` スクリプトを実行するだけで、`cmake` と `make` が実行され、プロジェクト全体がビルドされます。

```
./build.sh
```

ビルドが成功すると、実行可能ファイルが `build/app1/` と `build/app2/` の中に生成されます。

### アプリケーションの実行

ビルドされたアプリケーションを実行します。

```
# app1の実行
./build/app1/app1

# app2の実行
./build/app2/app2
```

### テストと解析

`test.sh` スクリプトは、ユニットテスト、静的解析、メモリ解析、カバレッジ計測を簡単に行うための統合ツールです。

#### ユニットテストの実行

`ctest` を使って、登録されているすべてのテストを実行します。

```
./test.sh unit
# or
./test.sh
```

#### 静的解析の実行

`cppcheck` を使って、ソースコードの問題を静的に解析します。

```
./test.sh static
```

#### メモリ解析の実行

`valgrind` を使って、テスト実行時のメモリリークや不正なメモリアクセスを検出します。

```
./test.sh memory
```

#### カバレッジ計測の実行

テストコードがソースコードのどの部分をカバーしているかを計測します。

```
./test.sh coverage
```

実行後、`workspace/coverage_report/index.html` にHTML形式のレポートが生成されます。ホストマシンのブラウザでこのファイルを開いて結果を確認してください。

#### すべてのチェックを実行

`unit`, `static`, `memory`, `coverage` のすべてのチェックを一度に実行します。

```
./test.sh all
```

### クリーンアップ

ビルドディレクトリやカバレッジレポートなど、生成されたすべての成果物を削除します。

```
./clean.sh
```

### 3\. 環境の停止

コンテナを停止し、関連リソースを削除します。

```
docker-compose down
```

## ディレクトリ構成

```
.
├── Dockerfile          # 開発環境の定義
├── compose.yml         # Docker Composeの設定
├── workspace/          # ホストとコンテナで共有される作業ディレクトリ
│   ├── app1/           # アプリケーション1
│   │   ├── src/
│   │   └── test/
│   ├── app2/           # アプリケーション2
│   │   ├── src/
│   │   └── test/
│   ├── CMakeLists.txt  # プロジェクト全体のCMake設定
│   ├── build.sh        # ビルドスクリプト
│   ├── test.sh         # テスト・解析スクリプト
│   └── clean.sh        # クリーンアップスクリプト
└── README.md           # このファイル
```
